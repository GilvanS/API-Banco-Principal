Novos Paths (Endpoints):
1. Operações da Conta (Dashboard e Extrato):
GET /accounts/{accountId}/balance
Summary: Obter saldo da conta.
Description: Retorna o saldo atual de uma conta específica.
Parameters:
accountId (path, string, uuid, required): ID da conta.
Responses: 200 (AccountBalanceResponse), 404 (Conta não encontrada), 401 (Não autorizado).
Security: bearerAuth
GET /accounts/{accountId}/statement
Summary: Obter extrato da conta.
Description: Retorna o extrato de transações de uma conta, com filtros opcionais por período e tipo de transação.
Parameters:
accountId (path, string, uuid, required): ID da conta.
startDate (query, string, date, optional): Data de início para o extrato.
endDate (query, string, date, optional): Data de fim para o extrato.
transactionType (query, string, enum: ['DEPOSIT', 'WITHDRAW', 'TRANSFER_IN', 'TRANSFER_OUT', 'PURCHASE', 'BILL_PAYMENT'], optional): Tipo de transação para filtrar.
Responses: 200 (StatementResponse), 404, 401.
Security: bearerAuth
2. Transações (Depósito, Saque, Transferência):
POST /transactions/deposit
Summary: Realizar um depósito.
Description: Permite realizar um depósito em uma conta específica.
Parameters:
depositRequest (body, required, DepositWithdrawRequest)
Responses: 200 (TransactionResponse), 400, 401.
Security: bearerAuth
POST /transactions/withdraw
Summary: Realizar um saque.
Description: Permite realizar um saque de uma conta específica.
Parameters:
withdrawRequest (body, required, DepositWithdrawRequest)
Responses: 200 (TransactionResponse), 400 (Saldo insuficiente), 401.
Security: bearerAuth
POST /transactions/transfer
Summary: Realizar uma transferência entre contas.
Description: Permite transferir dinheiro de uma conta para outra, podendo ser entre contas do mesmo usuário ou para outros usuários.
Parameters:
transferRequest (body, required, TransferRequest)
Responses: 200 (TransactionResponse), 400 (Saldo insuficiente, conta destino inválida), 401.
Security: bearerAuth
3. Cartões:
GET /cards
Summary: Listar cartões do cliente.
Description: Retorna uma lista de todos os cartões (débito e crédito) associados ao cliente logado.
Responses: 200 (CardListResponse), 401.
Security: bearerAuth
POST /cards/{cardId}/block
Summary: Bloquear um cartão.
Description: Bloqueia um cartão específico por ID.
Parameters:
cardId (path, string, uuid, required): ID do cartão a ser bloqueado.
Responses: 200 (CardStatusUpdateResponse), 404, 401.
Security: bearerAuth
POST /cards/{cardId}/unblock
Summary: Desbloquear um cartão.
Description: Desbloqueia um cartão específico por ID.
Parameters:
cardId (path, string, uuid, required): ID do cartão a ser desbloqueado.
Responses: 200 (CardStatusUpdateResponse), 404, 401.
Security: bearerAuth
GET /cards/{cardId}/invoice
Summary: Obter fatura do cartão de crédito.
Description: Retorna os detalhes da fatura de um cartão de crédito, incluindo valor total, valor mínimo e transações.
Parameters:
cardId (path, string, uuid, required): ID do cartão de crédito.
month (query, integer, optional): Mês da fatura (e.g., 6 para Junho).
year (query, integer, optional): Ano da fatura.
Responses: 200 (CardInvoiceResponse), 404, 401.
Security: bearerAuth
POST /cards/request
Summary: Solicitar novo cartão.
Description: Permite ao usuário solicitar um novo cartão (débito ou crédito).
Parameters:
cardRequest (body, required, NewCardRequest)
Responses: 201 (NewCardResponse), 400, 401.
Security: bearerAuth
4. Configurações:
PUT /users/password
Summary: Alterar senha do usuário.
Description: Permite que o usuário altere sua senha atual.
Parameters:
changePasswordRequest (body, required, ChangePasswordRequest)
Responses: 200 (SuccessResponse), 400 (Senha atual incorreta), 401.
Security: bearerAuth
PUT /users/notifications
Summary: Atualizar preferências de notificação.
Description: Permite ao usuário configurar quais tipos de notificações deseja receber.
Parameters:
notificationSettings (body, required, NotificationSettingsRequest)
Responses: 200 (NotificationSettingsResponse), 401.
Security: bearerAuth
GET /users/devices
Summary: Listar dispositivos conectados.
Description: Retorna uma lista dos dispositivos onde o usuário está logado.
Responses: 200 (ConnectedDevicesResponse), 401.
Security: bearerAuth
DELETE /users/devices/{deviceId}
Summary: Desconectar dispositivo.
Description: Remove um dispositivo da lista de sessões ativas do usuário.
Parameters:
deviceId (path, string, uuid, required): ID do dispositivo a ser removido.
Responses: 200 (SuccessResponse), 404, 401.
Security: bearerAuth
POST /auth/logout
Summary: Sair da conta.
Description: Invalida o token JWT atual, efetuando o logout do usuário.
Responses: 200 (SuccessResponse), 401.
Security: bearerAuth
5. Investimentos:
GET /investments/summary
Summary: Obter resumo de investimentos.
Description: Retorna um resumo do portfólio de investimentos do usuário, incluindo valor total investido, rendimento e distribuição.
Responses: 200 (InvestmentSummaryResponse), 401.
Security: bearerAuth
GET /investments/applications
Summary: Listar aplicações ativas de investimento.
Description: Retorna detalhes de cada aplicação de investimento ativa.
Responses: 200 (ActiveApplicationsResponse), 401.
Security: bearerAuth
POST /investments/simulate
Summary: Simular investimento.
Description: Simula o rendimento de um investimento com base em valor, período e tipo.
Parameters:
simulationRequest (body, required, InvestmentSimulationRequest)
Responses: 200 (InvestmentSimulationResponse), 400, 401.
Security: bearerAuth
POST /investments/apply
Summary: Realizar nova aplicação de investimento.
Description: Permite ao usuário realizar uma nova aplicação em um produto de investimento.
Parameters:
applicationRequest (body, required, NewInvestmentApplicationRequest)
Responses: 201 (NewInvestmentApplicationResponse), 400, 401.
Security: bearerAuth
GET /investments/savings-program
Summary: Obter status do programa de poupança programada.
Description: Retorna informações sobre a poupança programada do usuário.
Responses: 200 (SavingsProgramResponse), 401.
Security: bearerAuth
PUT /investments/savings-program/configure
Summary: Configurar programa de poupança programada.
Description: Configura ou atualiza as regras para a poupança automática.
Parameters:
savingsProgramConfig (body, required, SavingsProgramConfigRequest)
Responses: 200 (SavingsProgramResponse), 400, 401.
Security: bearerAuth
